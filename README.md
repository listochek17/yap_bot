# Проект: Yap Bot

Yap Bot — простая реализация Telegram-бота для магазина еды. Бот позволяет:

- Просматривать список категорий блюд
- Выбирать продукты внутри категории
- Увидеть цену выбранного продукта

Где смотреть код
- `main.py` — основные обработчики (старт, переход на сайт, показ категорий и продуктов)
- `pu_in_base.py` — работа с базой данных SQLite (`yap2.db`): функции создания/чтения таблиц и получения списка категорий/товаров
- `keyboards.py` — создание ReplyKeyboard для интерфейса
- `pars_evos.py` — (опционально) парсер для загрузки категорий и товаров из публичного сайта

Запуск локально
1. Перейдите в папку проекта:
```powershell
cd 'C:\Users\Улугбек\Desktop\Githab_correcting\yap_bot'
```
2. Создайте и активируйте виртуальное окружение, установите зависимости:
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
3. Создайте файл `.env` в этой папке и положите туда токен бота:
```
TOKEN=<ваш_токен_бота>
```
4. Запуск бота:
```powershell
python main.py
```

О базе данных
- Локальная база хранится в файле `yap2.db`. В репозитории этот файл игнорируется (`.gitignore`), поэтому база остается локальной и не попадает на GitHub.
- Если база пуста, можно заполнить её из JSON-файлов `category.json` и `products.json` (скрипт `pars_evos.py` собирает эти файлы с сайта). Функции для вставки в БД находятся в `pu_in_base.py`.

Замечания и рекомендации
- В `pars_evos.py` реализован минимальный парсер; перед массовым парсингом проверьте `robots.txt` и правила сайта.
- Для продакшна рекомендуется:
  - переключиться на официальный API для получения цен/каталогов (если доступен)
  - добавить обработку состояний (FSM) для диалогов
  - настроить логирование в файл и мониторинг
